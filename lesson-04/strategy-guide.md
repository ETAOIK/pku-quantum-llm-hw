# 在网页表达并测试新策略

更新日期：2026-10-16。状态：本地日线公式策略已实现。来源：[公式解析器](formula.py)、[回测网页接口](server.py)、[对应测试](tests/test_workbench.py)。本页属于实现说明和教学示例，不代表示例策略有效。

启动方式见 [README](README.md#打开可操作的回测网页)。选择“自定义策略公式”，给策略命名，填写以下两部分。

1. **选股评分公式**：给每个股票、每个日期计算分数，越高越优先选入。选择前 N 只后按目标仓位等权分配；不足 N 只时在可选股票间平分，完全没有合格股票时目标为现金。
2. **持仓条件**：决定当次信号是否可选，填 `True` 表示不加条件。条件不满足的已持仓股票会在下次计划调仓时请求卖出，仍受缺价、跳空和成交容量限制；不是盘中即时止损。

所有字段均在信号日收盘后使用，下一交易日开盘模拟执行。网页可设置持仓数、调仓间隔、日期、初始资金、目标仓位、费用、滑点与金额限额。调仓日沿用原始数据行序号的固定周期，并非每个自然周的固定星期。

## 可直接输入的例子

| 想法 | 评分公式 | 持仓条件 |
| --- | --- | --- |
| 买近期回落、仍在趋势线上的股票 | `-returns(close, 5)` | `close > ts_mean(close, 20)` |
| 买均线多头排列、过去两个月较强的股票 | `returns(close, 60)` | `ts_mean(close, 10) > ts_mean(close, 30)` |
| 兼顾动量和低波动 | `rank(returns(close, 20)) + rank(-ts_std(returns(close, 1), 20))` | `close > ts_mean(close, 60)` |
| 低波动组合 | `-ts_std(returns(close, 1), 60)` | `True` |
| 低波动且最近单日没有大跌 | `-ts_std(returns(close, 1), 20)` | `returns(close, 1) > -0.03 and close > ts_mean(close, 20)` |

这些是待测试的表达，不是对收益的承诺。`rank` 的作用是把不同量纲变成当时可投股票池内的百分位；例如把“过去 20 日收益”和“过去 20 日低波动”各自排名，再相加。没有排名直接相加会隐含数值尺度带来的权重。

## 字段与函数

| 名称 | 含义 |
| --- | --- |
| `close/open/high/low` | 复权收盘/开盘/最高/最低价，暂按原价乘累计因子构造 |
| `amount` | 当日成交金额，暂按人民币元解释 |
| `num_trades` | 当日成交笔数的暂定解释，不是成交股数 |
| `returns(x, n)` | `x / lag(x, n) - 1`，不填补缺失 |
| `lag(x, n)` | n 个交易日前的值 |
| `ts_mean/ts_std/ts_min/ts_max(x, n)` | 包括信号日在内的 n 日滚动统计；需完整 n 个非缺失观察，标准差采用 pandas 样本标准差 |
| `rank(x)` | 当日在基础可投股票池内升序百分位排名；缺失不排名，持仓条件不改变该排名的参照池 |
| `abs(x)` | 绝对值 |
| `where(条件, 值1, 值2)` | 满足条件取值1，否则取值2 |

支持加减乘除、括号、`< <= > >= == !=` 比较及 `and / or / not`。也支持带括号的逻辑 `& / \| / ~`；建议优先使用 `and/or/not`。除零、无穷和特征缺失不能变成有效选股分数；缺失数据的比较不视为满足持仓条件。窗口必须为 1–252 的正整数；例如 `lag(close, -1)` 会被拒绝，因为它要求未来数据。

为控制本地计算规模，每个表达式至多 600 字符及 100 个语法节点。不执行 Python `eval`，不允许导入、文件/网络操作、属性访问、索引、循环或任意函数调用。“检查公式”检查语法和历史窗口，实际运行还会检查有效分数和参数。

## 如何查看结果

- 顶部指标和曲线显示本次实际运行与相同日期、成本、仓位和调仓周期的基础可投池等权基准。持仓条件属于策略，不应用到基准上。
- 委托表包含请求、实际成交金额、费用和受阻原因；请求金额是滑点前的参考金额，成交金额按包含滑点的成交价计算，二者略有差异。
- 持仓表为调仓日和期末快照，份额是复权研究单位；每日账本另外记录每日资产和现金。未产生任何成交的有效策略显示现金路径，不能虚构收益。
- CSV 与本次设置会保存到 `runtime/<run-id>/`。运行列表保留当前服务会话；重新启动后仍可直接读取磁盘文件，当前网页不自动导入旧会话。

原始冻结实验仍可切回，所有新公式/参数运行标为“探索性运行”。日线只能表达当前框架的历史评分、筛选与计划调仓，盘中止损、逐笔挂单、期货保证金和自定义多腿执行需要扩展相应引擎与数据。真实分红、整手及历史涨跌停限制仍遵循 [原型边界](REPORT.md#账本与成交假设)。
