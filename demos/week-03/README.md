# 第三周实践课：历史回放与模拟交易原型

更新日期：2026-10-16。状态：本地原型已实现，真实 50 股票重建校验已完成；目录沿用第三周命名，作为第三节作业的 Task 1，教师评分标准尚待确认。

系统读取三份原始 Parquet，恢复历史订单簿，再让你在这个历史市场中提交模拟限价单。可以选择 50 只股票中的一只、手动或自动推进时间、查看 1 分钟 K 线和买卖十档、下单或撤单、检查资金持仓及导出结果。原始数据保持只读。

## 用一个例子走完整条交易链

1. 选择 `601688`，初始资金 `1000000` 元、期初可卖持仓 `0` 股，点击“开始 / 重置回放”。起点是 09:30，已经恢复开盘前事件留下的订单簿。
2. 推进至 `10:00:00`。应显示已处理 **25,065** 个事件，买一 **18.41 元 / 39,200 股**，卖一 **18.42 元 / 500 股**。十档与用户提供的同学截图一致。
3. 买入限价 `18.48` 元、`100` 股。因为卖一比你的限价便宜，模拟单立即以 **18.42 元**成交 100 股。现金变为 **998,158 元**，持仓和当日买入均为 100 股，可卖持仓仍为 0。
4. 尝试立即卖出这 100 股，会因可卖持仓不足被拒绝。这体现股票当日买入不可当日卖出的 T+1 约束。
5. 要观察排队：重置并再次推进到 10:00，以 `18.41` 元买入 100 股。同价前量最初为 **39,200 股**。推进 10 秒，本模型于 **10:00:08.720**根据新出现的对手剩余委托估计成交；成交记录会注明估计方式。
6. 要观察撤单：重置后挂一个低于买一的买单，查看资金冻结；撤销后未成交部分对应的资金释放。也可设置期初持仓来试验卖出冻结和成交。

“限价”是买入愿意付出的最高价或卖出愿意接受的最低价，实际主动成交价格可以更好。委托号只说明收到了委托，应以“成交记录”和账户变化判断是否成交。

## K 线与自动回放

K 线把真实竞价成交按自然分钟归组：第一笔为开盘价、最高/最低成交价为高低价、最后一笔为收盘价，成交股数相加得到分钟量。例如同一分钟依次成交 18.40、18.42、18.39、18.41，蜡烛对应开 18.40、高 18.42、低 18.39、收 18.41。

图只使用已经处理的成交事件，包含已观察到的开收盘集合成交，排除盘后固定价格通道；没有成交的分钟不补虚构蜡烛。最新一根分钟 K 线会随回放更新，直到这一分钟结束；它不是预先知道的完整分钟收盘价。横轴按有成交的分钟排列，午间断点标注，鼠标悬停可查看价量。

自动回放每次请求完成后再等待约一秒，按所选速度推进市场时间 1、10 或 60 秒。首次点击播放先同步服务端时钟；到 15:30 自动停止。点击暂停、手动推进、重置、下单或撤单都会停止自动播放，让操作发生在清楚的时刻。发生请求错误也会停下，不自动重试相对推进。后台节流、数据加载或处理耗时可能使实际播放变慢，因此速度表示每次推进多少市场秒，不是严格的墙钟倍率。

## 实现如何工作

| 层 | 代码 | 职责 |
| --- | --- | --- |
| 数据 | [data.py](sse_replay/data.py) | 分批读取 Parquet，统一整数分、股、毫秒；按时间、通道及业务序号组织事件 |
| 历史订单簿 | [book.py](sse_replay/book.py) | 以 `OrderOriNo` 关联新增剩余量、撤单、成交，保留逐单队列和全深度，聚合最优十档 |
| 规则 | [rules.py](sse_replay/rules.py) | 连续竞价时段、主板/科创板数量、价格单位、普通涨跌幅和价格笼子 |
| 模拟交易 | [broker.py](sse_replay/broker.py) | 主动按价格及时间优先成交、被动排队估计、剩余量撤单、资金持仓账本 |
| 回放会话 | [session.py](sse_replay/session.py) | 时间推进、开盘状态恢复、用户操作与市场事件衔接 |
| 本地网页 | [server.py](sse_replay/server.py) | Flask 接口、中文工作台、账户/订单/成交显示和 CSV 导出 |
| 校验 | [validate.py](sse_replay/validate.py) | 独立重建核对原始快照，输出逐股票结果与源文件指纹 |

这份沪市 `A` 消息是即时成交之后留下的剩余委托。因此历史订单簿不把它再次自动撮合；历史 `exe` 只扣已经在簿的相应订单。模拟用户订单使用独立编号和账本，不会污染历史基准簿。

时间查询取处理完 `Time <= 目标时刻` 全部事件后的状态。同一毫秒的事件继续保留各自业务顺序。没有事件的时间段沿用上一状态；界面只能向前推进，回到过去须重置。

模拟主动成交消费过的历史订单数量会被单独占用，直到真实成交/撤单消除相应数量，避免再次拿同一份历史流动性成交。十档展示的是历史基准量，模拟单和这份占用不计入其显示；所以买完 100 股后界面卖一仍可能显示历史的 500 股。

**52 项实现测试通过**，涵盖顺序/单位、剩余量语义、优先级、主动扫单、被动排队、撤单、占用防重复、主板/科创板约束、资金/T+1、API、源指纹绑定及分钟 OHLC/成交量的历史时点边界。浏览器验收确认播放/暂停、分钟推进与 K 线同步、输入委托暂停、撤单解冻、15:30 自动结束；验收时没有浏览器错误日志。另以真实 601688 做了 500 次随机操作探针：286 个订单、201 条成交，逐步现金、冻结、持仓、成交汇总和流动性占用检查通过。此探针说明账户守恒，不证明被动成交估计等于真实成交。

## 规则与原型边界

按数据日适用的[上交所交易规则（2026 年修订，2026-07-06 生效）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)实现普通 A 股连续竞价限价单约束；核查日期 2026-10-09。主板与科创板分别处理，不将 100 股整数倍规则套给科创板。

- 历史事件可以回放至 15:30，开收盘集合事件用于恢复历史状态，盘后通道单独统计；用户模拟委托和撤单仅支持连续竞价。
- **14:57 结束所有剩余模拟挂单并释放资源，是本原型的范围处理，不是交易所的真实失效规则。**未实现用户单参与集合竞价、盘后委托或市价单。
- 每只股票同时一笔在途模拟委托；切换股票须重置账户。这是教学简化，不是交易所限制。
- 固定历史未来、零手续费、零延迟。被动单加入已有同价队列末尾，前序撤单只减少前量，不直接产生成交；后续合格交易流或新增对手剩余委托可以触发估计成交。
- 日涨跌幅按已上市普通主板 10%、科创板 20% 假设；缺少 IPO、风险警示、停复牌等完整证券状态资料，未实现全部例外。
- 保存事件流和可查询订单簿，导出当前十档与本次订单/成交；未物化存储每个事件后的全量订单簿。
